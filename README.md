\# Agentic YouTube Content \& Video Automation Pipeline (Claude AI \& MCP)



An end-to-end \*\*Agentic AI \& MarTech Automation Pipeline\*\* built using \*\*Claude AI\*\* and a custom \*\*Python FastMCP Server\*\*. From a single prompt, it generates localized Tamil scripts, neural voiceovers, 1080x1920 vertical motion-graphics videos, and publishes Shorts directly to YouTube with SEO metadata.



\## Key Highlights

\- \*\*End-to-End Automation:\*\* Cuts manual video creation and publishing time from hours to \*\*under 2 minutes\*\*.

\- \*\*Tamil Unicode \& Neural Voice:\*\* Uses `Edge-TTS` for natural Tamil speech and Headless Edge/Chromium (HarfBuzz) for crisp Tamil text overlays.

\- \*\*FFmpeg Compositing:\*\* Automatically syncs audio duration, background motion, and text cards into a 1080x1920 MP4.

\- \*\*Safe YouTube Publishing:\*\* Uses YouTube Data API v3 with OAuth 2.0 authentication and private-by-default human review gates.
